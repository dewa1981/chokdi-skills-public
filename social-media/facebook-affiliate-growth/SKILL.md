# Facebook Page Reach & Shopee Affiliate Monetization

Class-level playbook for Patty's page (เรื่องราวของลูกรักน้องสโนว์) and any
small creator page: growing organic reach + earning via Shopee/TikTok affiliate.

## When to Use
- User asks how to @/tag followers, "เห็นก่อน" (See First), reach, engagement.
- User asks why an affiliate commission disappeared/was cancelled.
- User asks about FB features: Meta AI, auto captions, hashtags, Professional Dashboard.
- Content planning for the page (weekly system, captions, hashtags).

## Facebook Reach — core rules
1. **@ tagging**: type `@` + name in post/comment; limit ~50 tags/post but
   tagging >10-15 routinely looks like spam → FB suppresses the post.
   Only tag friends/followers of the page (non-followers can't be tagged).
2. **Mass-tagging to force reach = REACH PENALTY + blocks/unfollows.** Never
   recommend tagging everyone to force visibility.
3. **Legit "เห็นก่อน" (See First)**: followers tap ⋯ on the page →
   ตั้งค่าการติดตาม (Following) → เห็นก่อน (See First). Post a polite ask
   for followers to enable it — safest way to get posts on top of their feed.
4. **Groups**: share reels to relevant FB groups (mom groups, Chiang Rai
   groups) — often more reach than the page itself.
5. **Tag selectively**: 3-5 people who actually engage, with a reason.
6. Algorithm levers (recurring): post Reels daily 15-30s, reply comments
   within the first hour, useful content (recipes/tips) = shares+saves,
   affiliate links go in a PINNED comment (never the post body), golden hours
   (06-08 / 12:00 / 18-21 Thai time).

## Shopee Affiliate — commission rules (why money disappears)
- Commission only counts when the order **fully completes**: delivered +
  no return/refund within the ~15-day hold window. Cancel at any point = 0.
- **C2C (Non-CB) orders never pay**: banner "คำสั่งซื้อถูกยกเลิกค่าคอมมิชชั่น /
  คำสั่งซื้อไม่ถูกต้อง" means the buyer bought from an individual (C2C)
  seller — non-cashback type, ineligible from the start. Check the order
  type label before assuming loss.
- Order can be cancelled by: seller (out of stock), system (unpaid/auto-
  cancel), delivery failure — buyer need not press cancel.
- **Friends/family buying through your link = account-ban risk.** Shopee
  flags related-account purchases as fraudulent self-ordering and voids the
  commission; repeated cases can ban the affiliate account. Do NOT ask
  friends to "help" buy.
- Always generate the affiliate link from the Shopee Affiliate program
  (image-search the physical item), pin it in comments.

## Content System (20 นาที/วัน, batch with AI)
- Day: film 15-30s natural clips with the kid (no staging). Night: send clips
  to AI (สหาย) → AI cuts + writes caption + hashtags → user posts in 5 min.
- 7-day rotating pillars: จันทร์ cute moment / อังคาร kid menu (star) /
  พุธ development milestone / พฤหัส mom tip / ศุกร์ real life / เสาร์ photo
  post with question / อาทิตย์ weekly compilation.
- Captions in mom's voice (ค่ะ for Patty), end with a question (CTA).
- Kid-content safety: enable comment filtering, never post predictable
  daily routines (school/home times) that reveal location patterns.

## Pitfalls
- Never advise buying views/likes or "share to win" posts — page gets demoted.
- Auto-captions (Meta) + suggested hashtags are free and safe — enable them.
- FB has NO button to make AI "turn on visibility"; growth = content +
  consistency + fast replies (AI assists production, not algorithm bypass).
