# Chokdi Skills — Public Set

Skill **netral** yang aman dipublikasikan, dipakai sebagai sumber skill untuk Aperture.

- Tidak memuat kredensial, alamat internal, nama server, atau data bisnis.
- Skill internal/rahasia disimpan di repo privat (tidak di sini).
- Struktur: `<kategori>/<nama-skill>/SKILL.md` (+ file pendukung).

Aturan memori agent: MEMORY.md maksimal 8000 byte; kalau lebih -> cut dan simpan
isi yang dibuang ke memori jangka panjang (Hindsight/Honcho sesuai config).
